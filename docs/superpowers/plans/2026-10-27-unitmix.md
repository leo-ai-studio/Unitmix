# Unitmix (app mới) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Web app Unitmix: từ chỉ tiêu quy hoạch của lô → xếp mẫu tòa → tầng/căn → hầm → 3D → so sánh phương án, lưu dự án/PA trên Cloudflare, mỗi dự án một link.

**Architecture:** Monorepo 3 phần. `scripts/` chép và chuẩn hoá thư viện CAD từ repo cũ thành JSON tĩnh trong `web/public/lib/`. `web/` là SPA Vite + TypeScript + Preact, bản vẽ 2D bằng SVG, 3D bằng three.js, mọi phép tính chỉ tiêu là hàm thuần trong `web/src/tinh/`. `worker/` là API Hono trên Cloudflare Workers + D1, lưu dự án và trạng thái PA dạng JSON, ghi phải kèm mã sửa.

**Tech Stack:** Python 3.12 + pytest (script thư viện); Node 24, Vite 6, TypeScript 5, Preact 10, three.js, dxf-parser, SheetJS (xlsx), Vitest; Hono 4, Wrangler 4, D1.

**Spec:** `docs/superpowers/specs/2026-10-27-unitmix-moi-design.md`

- Endpoint (JSON):

  - `GET /api/du-an/:ma/pa/:id` → `{id, ten, trang_thai}`.
  - `PUT /api/du-an/:ma/pa/:id` (header `X-Ma-Sua`) body `{ten, trang_thai, tom_tat}` → 200; tạo mới nếu chưa có.
  - `POST /api/du-an/:ma/pa/:id/nhan-ban` (header `X-Ma-Sua`) → `201 {id}`.
